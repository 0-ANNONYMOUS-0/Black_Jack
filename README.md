# 🃏 Blackjack Game

A simple single-player Blackjack game that runs in the browser, built with HTML, CSS, and vanilla JavaScript.

🔗 **Live Demo:** [add your GitHub Pages / Vercel link here]

---

## 🎮 How to Play

1. Click **START GAME** to get two random cards.
2. Click **ADD NEW CARD** to draw another card.
3. Number cards count at face value, J/Q/K count as 10, and an Ace counts as 11.
4. Get exactly **21** for a Blackjack 🎉
5. Go over 21 and it's **Game Over**.

---

## ✨ Features

- Random card generation
- Live display of your cards and running sum
- Blackjack (21) and bust (over 21) detection
- Player name and chips display
- Dynamic messages that update after every move

---

## 🛠️ Tech Stack

- **HTML5**: page structure
- **CSS3**: styling and casino-themed layout
- **JavaScript (ES6)**: game logic and DOM manipulation
